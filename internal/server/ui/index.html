    Freigabe von „“ ändern

    Der Crawler muss danach neu installiert werden. Die Freigabe ist auf dem Crawler-Rechner fest hinterlegt. Das ist Absicht: So kann ein kompromittierter Server die Grenzen eines Crawlers nicht aus der Ferne erweitern. Bis zur Neuinstallation scannt der Crawler nur innerhalb seiner alten Freigabe, offene Jobs werden verworfen. Netze, Inventar und Verlauf bleiben erhalten.

    Mehrere Bereiche mit Komma trennen. Alle Netze dieses Crawlers müssen in die neue Freigabe passen.

    Crawler anlegen

    Nur private Adressbereiche. Danach erscheint ein Installationsbefehl für den Crawler-Rechner (Debian/Ubuntu/Raspberry Pi OS mit systemd). Er übernimmt die Freigabe fest in die lokale agent.json.

    Webhook in Discord anlegen

    Discord-Server → Servereinstellungen → Integrationen → Webhooks → „Neuer Webhook“, Kanal wählen, „Webhook-URL kopieren“ und hier einfügen.

    Die URL ist ein Zugangsschlüssel: Wer sie kennt, kann in den Kanal schreiben. Sie wird nur in der Datenbank gespeichert und nie wieder angezeigt. Gesendet werden nur Änderungen ab dem Speichern; der Initialbestand nie. Mehrere Änderungen kommen gebündelt in einer Nachricht.
